# Project governance

mosque.build is stewarded by ummah.build. Maintainers set product direction, review contributions and protect the project’s safety, evidence, privacy, brand and rights boundaries.

## Decision model

- Small fixes: maintainer review after automated checks.
- Product or data changes: issue discussion plus maintainer review.
- Schema, security, privacy, regulated, religious-content, jurisdiction or architecture changes: documented proposal and appropriate specialist review.
- Breaking changes: migration notes and an explicit release decision.

No software maintainer review substitutes for qualified professional, authority, legal, tax, accessibility, security, privacy or religious-content review where required.

## Status and roadmap

Feature status uses the vocabulary in `AGENTS.md`; inclusion in the roadmap is not a delivery claim. `docs/NEXT_BUILD.md` is the contributor-oriented work queue. GitHub issues should remain smaller than roadmap epics and must state acceptance tests and review gates.

## License blocker

The repository does not yet declare an outbound open-source license. The rights holder must deliberately select and publish one after reviewing source archives, visual assets, third-party rights and contribution terms. Until then, public visibility alone does not grant reuse rights.
