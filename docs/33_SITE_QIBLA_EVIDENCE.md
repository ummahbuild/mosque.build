# Site and qibla evidence workflow

Status: `executable`.

The design workspace now records provisional boundary dimensions and qibla bearing with acquisition method, accuracy state, observation date, reviewer role, source reference, unresolved questions and a share-safety confirmation. It deliberately does not request coordinates or a precise address.

Users can explicitly send the provisional width, depth and bearing into the schematic. The receiving plan is marked measured-but-unverified and continues to display its professional review gate. The evidence record is allowlisted in project export and restore.

This advances P1 design-workflow item 3. Credential validation, survey files, source attachments, coordinate reference systems, signed review and multi-user permissions remain future work.
