# External Dependency Policy

External dependencies are deliberately separated from core domain logic.

- The project must still open and preserve data if an AI provider is unavailable.
- Marketplace can begin as **directory + outbound link + RFQ**, postponing transactional complexity.
- Permit and demographic intelligence can degrade to source-backed manual records where APIs do not exist.
- 3D domain state remains portable across renderer adapters.
- Book/product prices are observations, not timeless product properties.
- No demographic engine may infer a community's school of thought from ethnicity/national origin; preference must come from explicit mosque/community configuration or reviewed local evidence.
