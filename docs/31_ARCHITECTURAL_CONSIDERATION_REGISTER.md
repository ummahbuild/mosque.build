# Architectural consideration register

Status: `executable`.

The design workspace now contains 25 editable review prompts spanning worship, arrival, accessibility, water, community life, climate and project delivery. Users can search and filter the register, carry prompts into review, see connected systems and the expected community, professional or authority gate, persist choices on-device and export a portable JSON register.

The prompts make coordination questions visible; they do not establish code compliance, religious validity or technical adequacy. The register is included in whole-project export and restore.

This increment advances the design workflow's adjacency, accessible-journey, wudu-flow, climate and review-responsibility requirements. Measured route geometry, code rules, performance simulation and reviewer credentials remain future work.
