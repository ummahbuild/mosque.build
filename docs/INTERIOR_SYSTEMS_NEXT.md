# Interior systems — next development plan

Status vocabulary follows the repository contract: `concept | specified | scaffolded | executable | source_backed | beta | production_ready`.

The implemented foundation is `executable`: semantic interior components, event-mode bundles, editable placement and quantity, Three.js instancing, GLB export, storage-gap arithmetic, care/evidence gates, project packaging, and a marketplace requirements handoff.
