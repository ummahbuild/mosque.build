# Waqf, Qurans & Islamic Books Marketplace

## Objective
Allow a donor to support a verified mosque/library by gifting requested knowledge resources or contributing to an approved library/waqf fund.

## Modes
1. **Wishlist gift** — mosque requests a specific edition/title/quantity.
2. **Curated bundle** — reviewed collection for a use case (new Muslims, youth, Arabic, tafsir, seerah, etc.).
3. **External purchase** — outbound link to publisher/bookseller/marketplace.
4. **Bulk RFQ** — mosque requests institutional pricing.
5. **Cash contribution** — contribution earmarked for an approved library/education fund, subject to local/legal/religious governance.

## Filters
- content type: Qur’an, translation, tafsir, hadith, fiqh, seerah, aqidah, Arabic, children, new Muslim, reference
- school/tradition metadata where a book itself has a documented scholarly/legal tradition
- language
- translation
- transliteration
- script/edition
- age/reading level
- format
- availability
- seller/source
- mosque wishlist priority
- reviewed/curated status

## School-of-thought safety
Do **not** infer madhhab from ethnicity or national origin. Community recommendations may use:
- explicit mosque profile,
- imam/library curator settings,
- declared curriculum,
- reviewed local survey,
- user-selected preference.

## Product/source record
Each external offer should store:
- canonical work/title identity
- edition/ISBN where applicable
- language/script
- translator/editor/publisher
- content/tradition tags with provenance
- seller
- outbound URL
- price/currency observed at
- availability observed at
- shipping region if known
- rights for cover image/metadata
- affiliate relationship disclosure
- review state

## Recommendation inputs
Location can inform:
- language availability,
- shipping feasibility,
- local booksellers,
- climate/storage concerns,
- currency,
- age mix and explicitly sourced demographic signals.

Community profile can inform:
- youth/new-Muslim demand,
- class/curriculum needs,
- language gaps,
- current inventory gaps,
- requested titles.

All recommendations must include **why this is recommended** and allow mosque administrators to override them.
