# mosque.build — Scan → Room Conversion → Budget → Editor v18

This module makes existing-space conversion a first-class workflow.

## Core flow
Scan room/building -> verify dimensions -> existing model -> select room -> choose target use ->
qibla/prayer layout -> identify demolition/new work/services -> estimate cost + duration ->
flag permit/professional review -> save scenario -> source products -> fund/build -> handover.

## Editor behavior
Existing, demolition, new work and reuse are separate visual layers.
A room can be converted directly from the editor using presets such as Prayer Room, Wudu, Madrasa or Community Room.

## Budget
Every conversion automatically updates quantities, repair scope, fit-out scope, product needs, procurement, schedule, funding gap and lifecycle costs.

## Safety/accuracy
Phone/LiDAR scans are provisional unless verified. Never infer structural safety or absence of hazards from visual capture alone.
