# mosque.build — 3D Product Designer System v16

## Purpose
Turn real vendor products and generic specifications into reusable design objects that can be placed in mosque projects.

## Pipeline
Vendor/product -> authoritative dimensions/specs -> 3D/BIM ingest or parametric placeholder -> unit/origin normalization ->
anchors/connections/clearances -> LOD/texture optimization -> technical review -> 3D library -> designer placement ->
compatibility -> quantity -> cost -> procurement -> installation -> commissioned asset.

## Compatibility
Compatibility is not visual only. It includes geometric fit, host, services, clearances, maintenance access, accessibility,
technical attributes, budget, lead time and delivery region. Professional-review items remain explicitly gated.

## Onboarding
Separate onboarding exists for vendors, designers, 3D modelers and mosque project teams.

## Rendering
A decorative/high-detail mesh may differ from the authoritative design/BIM representation. Both remain linked to the same product/version.

## Vendor lock-in
Any named vendor product can be replaced with its generic specification counterpart. Product placement should help design/procurement without making the project dependent on one supplier.
