# Skill: Maintain Shadow Mosque Profiles & Claims

Run whenever directory ingestion, mosque claims, profile provenance, provider merge, domain verification, or admin ownership changes.

## Required
1. Shadow profiles must remain visibly unclaimed until approval.
2. Every public field must keep field-level provenance.
3. Domain verification proves domain control, not necessarily legal authority over the mosque.
4. DNS TXT is the default strong automated method.
5. High-risk claims route to manual review.
6. Claims changing donation recipient, tax status, or existing ownership are always manual.
7. Update the living backend process registry and diagrams.
8. Add/adjust RLS tests.
9. Never overwrite independent architecture/history sources with unsourced admin edits.
10. Record revocation/dispute history.
