# mosque.build — Global Vendor Directory v13

Seeded real vendor examples: 45

## Marketplace principle
The directory distinguishes:
- discovered vendor
- source-verified vendor
- platform-claimed vendor
- verified reference project
- disputed reference

A supplier's own site is evidence that it markets a product/service. It is not independent proof of every performance or project claim.

## Vendor shadow profiles
Vendor profiles may be created from permitted public business sources and remain unclaimed. Vendors can claim profiles using the same domain-verification system as mosque organizations, followed by risk/admin review.

## Real mosque references
A vendor can attach a product/service to a real mosque profile. Public display must identify verification level and exact scope of work.

## Coverage goal
Populate every equipment/craft/construction category by region and delivery capability, then enrich with product offers, prices, lead times, warranty, BIM/CAD, samples and project references.
