# mosque.build — Integrated Marketplace / Project Commerce v14

## Core principle
Marketplace selection is integrated with design, cost, schedule, fundraising, construction and operations.

Browse -> Compare -> Save -> Add to mockup -> Auto quantity -> Project cart -> Technical review -> Sample/Submittal ->
RFQ -> Quote -> Landed cost -> Approval -> PO -> Manufacturing -> Shipping/Customs -> Delivery ->
Install -> Commission -> Asset register.

## Important distinction
"Add to cart" is a project-planning action, not necessarily an e-commerce checkout. Named products remain provisional until project-specific technical approval.

## Advanced compare
Compare technical fit, installed/landed cost, lifecycle maintenance, lead time, reference projects, warranty, local repairability, supplier confidence and opening-date risk.

## Design integration
Products can bind to modeled objects/surfaces. Product changes update quantities, renders, cost, procurement and timeline. Projects can always revert named products to generic specifications to avoid vendor lock-in.

## Public reusable designs
Public/copyable mosque mockups can include named product references when licensing/rights allow, but copied projects re-evaluate availability, shipping, codes, costs and geography.
