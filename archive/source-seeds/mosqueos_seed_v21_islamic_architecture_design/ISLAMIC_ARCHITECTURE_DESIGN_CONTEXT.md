# mosque.build — Islamic Architecture & Design Intelligence v21

This module deepens Islamic architectural design without collapsing diverse regional traditions into a single style.

## Populated systems
- 96 Islamic architecture/design features
- 20 pattern/ornament seeds
- 11 regional style packs
- 8 mosque typology seeds
- 7 material/color palettes
- 10 generator API contracts
- 39 editor presets

## Historical grounding
Hypostyle and four-iwan mosque types are treated as historically distinct typologies. Museum/reference sources seed muqarnas, geometric interlace and vegetal arabesque examples.

## Critical rule
Historical facts, regional style descriptions, generative rules and contemporary design suggestions are different data classes. The editor must never imply that a generated design is an authentic reconstruction merely because it uses a historical pattern family.

## Calligraphy rule
Do not auto-fill Qur'anic verses or sacred text as generic decoration. Use placeholder inscription zones until exact text and specialist/religious review are provided.

## Style mixing
The editor allows deliberate hybrid contemporary design, but shows which regional/style grammars are being combined and warns when the user enters stricter reconstruction/authenticity mode.
